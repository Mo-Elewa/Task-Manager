# Task Manager

A Python-based Task Manager application that helps users organize and manage their daily tasks.

## Features
- Add new tasks.
- Display all tasks.
- Search for tasks.
- Update existing tasks.
- Delete tasks.
- Mark tasks as completed.
- Save and load tasks using JSON.

## Technologies Used
- Python
- Object-Oriented Programming (OOP)
- JSON

## Project Structure
- main.py
- manager.py
- Operation.py
- task.py

## How to Run
Run the following command:

python main.py
